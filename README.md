# RPS
This is my rock paper scissors project for the Odin Project's js fundamentals. 
Currently, it allows the player to pick from three options using buttons and pits that choice against a randomly generated bot choice.
The player can play five rounds total against the bot, after which a final victor will be decided and the game will reset. 
It's simple, but it works. 

I'm looking to add some animations, fancier graphics, more gamemodes and a home screen later down the line, but as it stands now, i'd call this complete.
Hope you have fun with it!
